Closer v2.5, tres perfiles

Tres conversaciones con el prompt versión 2.5 sin tocarle una coma: sin apéndice del sistema y sin corregir lo que el modelo escribió. Cada prospecto entra por un canal distinto y con otro tono, para ver si el radar aguanta aperturas que no se parecen.

Sin intervención. El prompt va literal y la salida se envía tal cual. La verificación igual corre, pero solo anota al pie de cada mensaje — no cambia nada. Las observaciones están aparte para que se distingan de lo que dijo el agente.
Un bloque quedó fuera. En el turno donde el inversor pregunta por estructurar varios créditos, el v2.5 indica ofrecer «Estructuración Simultánea» aprovechando la latencia de actualización de la CMF, para que cada banco evalúe sin ver los otros dos créditos en curso. Ese guion no se redactó. El agente responde ese turno con el resto del arsenal: segundo titular, Bono Pie y compra escalonada.

Lo que el agente escribió

Los mensajes del prospecto están escritos; los del agente los produjo el prompt v2.5. Bajo cada mensaje del agente van las observaciones de la verificación, cuando las hubo.

Para reproducirlo

npm run closer -- A --v25 --crudo · B · C

El prompt v2.5 está guardado literal en src/lib/agente/persona-v2.ts (SISTEMA_CLOSER_V25). Las respuestas del modelo son una grabación —este entorno no tiene credencial de API—; el prompt, el inventario y la verificación son los reales.
