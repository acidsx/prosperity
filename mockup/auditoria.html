Qué hizo decir el v2.0

Se corrió el prompt versión 2.0 contra la misma conversación con la que se probó la versión 1: un inversionista que quiere cuatro departamentos. El modelo siguió las instrucciones al pie de la letra. El verificador rechazó el mensaje completo.

Siete incumplimientos en un solo mensaje, tres de ellos con una norma vigente en contra. El prompt no falló por tono ni por estilo: las frases que entrega como ejemplo contienen afirmaciones que la ley chilena desmiente.

Lo que esta prueba encontró en el sistema

El v2.0 también destapó un agujero propio

corregido
«cap rate en 5,5% anual» — pasó la primera verificación

La rentabilidad inventada del prompt calzó por redondeo con el 6 de las «6:00 p. m.» de la agenda, que el verificador estaba tomando como cifra citable. Se arreglaron dos cosas: las horas ya no entran al conjunto de cifras permitidas, y la tolerancia por redondeo quedó restringida a montos de 100 o más. Con eso el 5,5% se rechaza.

Probar un prompt agresivo no sirve solo para evaluar el prompt: sirve para encontrar dónde el guardarraíl era más blando de lo que parecía.

Para reproducirlo

npm run closer -- B --v2 · npm run auditoria

El prompt v2.0 se guarda literal en src/lib/agente/persona-v2.ts, sin corregirle nada: si se editaran esas frases, la prueba dejaría de medir algo. Las respuestas del modelo son una grabación —este entorno no tiene credencial de API—; el prompt, la ficha y la verificación son los reales y corren en cada prueba.
